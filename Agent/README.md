# Agent Artifacts & Documentation

Folder ini digunakan secara eksklusif untuk menyimpan artefak perencanaan (`Agent/<descriptive>-plan.md`), PRD (Product Requirement Document), dan rencana remediasi/audit teknis bagi AI Agent maupun developer.

## Aturan Penggunaan

1. **Lokasi File**: Semua perencanaan jangka panjang, dokumen arsitektur, dan instruksi spesifik agent harus disimpan di dalam direktori `Agent/`.
2. **Penamaan File**: Gunakan format `kebab-case.md` yang deskriptif (contoh: `audit-remediation-plan.md`, `prd-feature-x.md`).
3. **Kerahasiaan**: Dilarang menyimpan kredensial, API key, token auth, atau data sensitif (`.env`) ke dalam folder ini.
4. **Pemeliharaan**: Perbarui dokumen saat ada perubahan arsitektur atau fase penyelesaian task.
