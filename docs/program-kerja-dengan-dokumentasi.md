## Catatan Migrasi

- Schema database yang dibaca laporan ini masih legacy: tabel `program_kerja` belum memiliki `publicationStatus`, `periodId`, `divisionId`, atau `executionStatus`.
- Data Program Kerja tidak diubah selama pembuatan laporan.
- Referensi gambar yang tercantum adalah data aktual dari kolom `foto1`?`foto6`, bukan hasil scan ulang folder sumber.
- File fisik diverifikasi terhadap `apps/web/public/<path database>`.
- Sebelum sinkronisasi schema, migration additive harus mempertahankan seluruh record dan path foto ini.
- Script import legacy memiliki operasi `deleteMany()`; jangan menjalankannya sebagai bagian dari sinkronisasi aman.
